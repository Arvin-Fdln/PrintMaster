# PrintMaster — PDF Print Cost Analyzer

A professional desktop app for print shop businesses.

## Features
- Scan PDF files and detect color vs B&W pages
- Auto-detect paper size (Letter, Legal, A3/A4)
- Custom pricing per page type
- Generate customer quotations
- Job history tracking
- PIN lock security
- Dark mode support

## Installation (Windows / Mac / Linux)

### Requirements
- Node.js 18+ (download from https://nodejs.org)

### Steps
1. Extract this folder anywhere on your computer
2. Open Terminal / Command Prompt inside the folder
3. Run: `npm install`
4. Run: `npm start`

### Build a native installer (optional)
- Windows: `npm run build:win`  → creates a .exe installer in /dist
- Mac:     `npm run build:mac`  → creates a .dmg in /dist
- Linux:   `npm run build:linux` → creates an AppImage in /dist

## First Run
- On first launch, no PIN is required
- Go to Settings to set your business name, pricing, and optional PIN lock
